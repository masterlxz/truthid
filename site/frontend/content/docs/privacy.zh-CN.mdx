_最后更新:2026-10-01。适用于 TruthID Desktop(Windows 和 Linux)以及 TruthID 移动应用。_

TruthID 是一款自主身份与凭证管理器。**不存在 TruthID 服务器,也没有 TruthID 账户。** 你在应用中存储的任何内容都不会发送给 TruthID 项目,项目也不收集使用数据、分析数据或崩溃报告——应用不包含任何遥测代码。本页说明应用访问和存储什么、哪些数据留在你的设备上、哪些数据会离开设备以及去向何处、保留多久,以及你可以控制什么。

关于威胁模型以及密钥如何受到保护,请参阅[安全模型](/docs/security#desktop-the-local-signer-service)。

## 责任方

TruthID 是由 [masterlxz](https://github.com/masterlxz) 以 MIT 许可证发布的开源软件。由于项目不运营任何接收你数据的服务,因此对于你保存在应用中的内容,项目不作为数据控制者。下列第三方网络在应用与其通信时会收到有限的技术数据;这些数据适用它们各自的政策。

问题或请求:[github.com/masterlxz/truthid/issues](https://github.com/masterlxz/truthid/issues)。

## 应用访问和存储什么

| 信息 | 保存位置 |
|---|---|
| 私钥:设备密钥、保险库密钥、本地钱包密钥、Arweave 钱包 | 操作系统密钥环(Windows 为凭据管理器,Linux 为 Secret Service;移动端为基于 Android Keystore 的安全存储 / iOS Keychain)。如果桌面密钥环不可用,应用会退回到 `~/.truthid`(Windows 为 `%USERPROFILE%\.truthid`)中的普通文件,并显示警告。 |
| 保险库条目:密码、通行密钥(passkey)、已保存的地址、支付卡、笔记 | 在你的设备上加密保存(`vault.enc`)。卡号和 CVV 在此基础上还有额外一层加密。 |
| 保险库文档(你附加的文件) | 加密保存在同一文件夹的本地缓存中。 |
| 身份数据:用户名、控制者钱包地址、设备公钥、监护人 | 在本地保存,并登记在公共区块链上(见下文)。 |
| 应用锁密码 | 只保存派生后的加密数据块,绝不保存密码本身。 |
| 你为备份、恢复或 Bitwarden 导入而选择的文件 | 仅通过操作系统的文件对话框读取或写入,且只限你选择的那个文件。 |
| 摄像头(二维码扫描器) | 实时用于扫描二维码。图像不会被保存,也不会发送到任何地方。 |

除非你执行下一节中的某项操作,否则此表中的所有内容都留在你的设备上。

## 哪些内容会离开你的设备,以及去向何处

**区块链(Base 网络)。** 创建身份、注册设备、设置监护人、开启会话以及发布保险库指针,都是链上交易。这些数据是**公开且永久的**:你的用户名、控制者地址、设备公钥、会话哈希、监护人配置,以及指向你已发布保险库的指针。它们绝不是私密的,也无法删除。为了读写链上数据,应用会联系公共 RPC 提供商(`mainnet.base.org`、`base-rpc.publicnode.com`、`base.drpc.org`),对于智能账户交易,还会联系 Pimlico bundler(`api.pimlico.io`)。这些提供商能看到你的 IP 地址和你查询的地址。

**Arweave。** 发布保险库时,每个条目、索引它们的清单以及所有附加文档都会**先在你的设备上加密**,然后通过 `arweave.net` 上传到 Arweave(你也在那里查询钱包余额和交易)。Arweave 存储的是密文,但其存在、大小和时间是公开的,而且 Arweave 上的数据是**永久的,无法删除**。日后任何获得你保险库密钥的人都可能解密已发布的内容。

**IPFS 网关。** 较旧的保险库数据块通过内容 ID 经由公共网关(`ipfs.io`、`dweb.link`)获取,这些网关能看到你的 IP 地址和你请求的内容 ID。

**你配置的固定(pinning)服务。** 在保险库设置中,你可以添加自选的 IPFS 固定服务(例如 Pinata 或 Kubo 节点)。应用会把加密的保险库数据块以及你输入的 API 密钥或令牌发送给它;该密钥保存在你设备的安全存储中,绝不会发送到其他任何地方。项目不选择、不运营任何固定服务,也不从中接收数据,你所选的服务能看到你的 IP 地址和加密内容。

**钱包连接(移动端)。** 如果你通过连接外部钱包来创建或管理身份,移动应用会通过 Reown AppKit 库使用 WalletConnect。配对过程以及你批准的请求会经由 Reown/WalletConnect 中继及其钱包目录传递,它们能看到你的 IP 地址、已连接的钱包地址,以及转发给你钱包的交易或签名请求。应用使用项目 ID 以及元数据 `TruthID` / `masterlxz.github.io/truthid` 向该服务表明身份。只有在你使用钱包连接流程时才会发生这种情况。

**更新。** 应用会检查 `github.com/masterlxz/truthid` 的最新发布版本(GitHub releases API)以获知新版本。GitHub 能看到你的 IP 地址和应用版本。

**字体。** 界面从 Google Fonts(`fonts.googleapis.com`、`fonts.gstatic.com`)加载字体,其能看到你的 IP 地址。

**你电脑上的其他应用。** 运行时,桌面应用只监听 `127.0.0.1`,以便 TruthID 浏览器扩展和其他本地应用可以请求它签名、固定(pin)内容、编辑保险库,或自动填充地址或支付卡。每个此类请求都会等待你在应用中明确批准。只会返回你批准的内容:一个签名,或你在对话框中选择的那一个地址或卡。有两种回答无需批准:应用正在运行,以及保险库中是否保存有支付卡或地址。参见[安全模型](/docs/security#desktop-the-local-signer-service)。

**你登录的网站。** 当你批准登录时,应用会对一个挑战进行签名,并将签名和你的公开身份(用户名和设备地址)发送到发起请求的网站的回调 URL。在你批准之前,手机会显示该网站的真实来源。

应用不出售数据,不展示广告,也不与广告商或数据经纪人共享数据。

## 保留与删除

- **在你的设备上:** 数据会一直保留,直到你删除。在应用中移除条目会将其从本地保险库中删除。卸载应用**不会**删除 `~/.truthid`(Windows 为 `%USERPROFILE%\.truthid`)或服务名称 `truthid` 下的密钥环条目;请自行删除以清除所有本地数据。密钥环条目可在凭据管理器(Windows)或你的密钥环工具(Linux)中移除。
- **在移动端:** 卸载应用会移除其本地数据。在 Android 上,安全存储中的密钥会随之删除。在 iOS 上,Keychain 项目可能在卸载后依然存在,因此重新安装的应用可能仍能找到保险库密钥。
- **在区块链和 Arweave 上:** 已发布的数据是永久的。在本地删除条目并重新发布,会将其从你当前的清单中移除,但此前的加密版本仍保留在 Arweave 上。轮换保险库密钥可以保护今后的发布;不会抹除过去的发布。
- **在第三方提供商处:** RPC 提供商、Pimlico、IPFS 网关、固定服务、Reown/WalletConnect、GitHub 和 Google Fonts 会按其各自政策所述保留日志;TruthID 项目无法访问或控制这些日志。

## 你的控制权

- 决定存储什么,以及是否发布保险库。从未发布的保险库绝不会离开你的设备。
- 批准或拒绝来自其他应用的每一个签名、pin、保险库编辑和自动填充请求。
- 在设置中开启应用锁,这样打开应用时会要求输入密码。
- 在设置中导出保险库的加密备份,并进行恢复。
- 轮换保险库密钥。
- 配置用于恢复的监护人,或者不配置——没有监护人,丢失的控制者钱包将无法恢复。
- 如果不想依赖公共提供商,可使用你自己的 RPC 端点,或运行你自己的节点。

## 儿童

TruthID 并非面向儿童,项目也不会有意收集任何人的个人信息。
